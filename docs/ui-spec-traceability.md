# UI Spec Traceability Matrix

Tài liệu đối chiếu các mã yêu cầu nội bộ (spec IDs) đã được lược bỏ khỏi giao diện người dùng (UI copy) nhằm giữ trải nghiệm sạch, dễ đọc — đồng thời bảo toàn đầy đủ khả năng truy vết giữa nghiệp vụ, thành phần giao diện và API / model backend.

> **Ánh xạ thuật ngữ UI ↔ Backend (chốt 2026-11-25):**
> - **Organization** (UI) ↔ `Project` (backend model / `/api/projects/{project_id}/`)
> - **Project** (UI, CVAT project) ↔ `Dataset` (backend model)
> - **Task** (UI, CVAT task) ↔ `Batch` (backend model)
> - **Job** (UI, CVAT job) ↔ `Job` (backend model)

## Nguyên tắc bảo trì

1. **Không đưa mã spec nội bộ lên UI text** (tiêu đề, nhãn cột, badge, thông báo, banner, FAQ).
2. Khi bổ sung hoặc điều chỉnh quy tắc nghiệp vụ gắn với mã đặc tả mới, cập nhật trực tiếp vào bảng trên kèm đường dẫn component và endpoint/model tương ứng.
3. Giữ nhất quán thuật ngữ CVAT trên toàn giao diện: **Organization** (không dùng "dự án" khi chỉ đơn vị tổ chức), **Project** (thay cho "Dataset"), **Task** (thay cho "Batch"), **Job**.
